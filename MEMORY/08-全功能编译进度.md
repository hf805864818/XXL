主要修法：
1. 删除 `return` 之后的不可达实现（大量编译错误来自这里）。
2. 统一头文件/实现/属性的类型（`NSData`/`NSMutableData`、`NSArray`/`id`、block 签名）。
3. 补缺失声明与 import（`objc/message.h`、`mach-o/dyld.h`、`dlfcn.h`、`sys/stat.h`、`spawn.h`、`MetalPerformanceShaders`）。
4. 修 ARC bridge（`CFStringRef`/`AXUIElementRef`/`void *`）。
5. 修逆向错发消息：AccessibilityManager / HIDManager / AppManager 的 selector 被错发给 Executor。
