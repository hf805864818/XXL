# 01 · 编译与安装

## 环境

| 需要 | 说明 |
|---|---|
| macOS + Xcode Command Line Tools | 交叉编译 arm64 / arm64e |
| Theos | `export THEOS=~/theos`，需带 iOS SDK（14.0+） |
| dpkg | `make package` 用它打 deb（Theos 自带） |
| 设备 | 越狱（rootless 或 roothide 均可，路径已兼容 `/var/jb`） |

安装 Theos（若还没有）：

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/theos/theos/master/bin/install-theos)"
export THEOS=~/theos
# 确认 SDK 在位
ls $THEOS/sdks | grep iPhoneOS
```

## 编译

```bash
cd PetDFY_Editable
make clean
make            # 只编译：.theos/obj 下出三个 dylib
make package    # 出 deb：packages/com.ojbkclub.petdfy_0.1.8-editable_*.deb
```

工程一次编三个产物（`Makefile` 里三段 `TWEAK_NAME`）：

| 产物 | 源 | 作用 |
|---|---|---|
| `PetDFY.dylib` | `src/Core` + `src/Sources` + `src/Ext` | 主体：桌宠、渲染、AI、可编辑化扩展 |
| `PDFYEnhance.dylib` | `src/Aux/PDFYEnhance.m` | 透明度 / 仅主屏 / 单击气泡 |
| `PDFYSecurity.dylib` | `src/Aux/PDFYSecurity.m` | 数据目录 0700、密钥文件 0600 |

## 安装

```bash
export THEOS_DEVICE_IP=192.168.1.50
export THEOS_DEVICE_PORT=22       # rootless 一般还是 22
make install
```

或手动：

```bash
scp packages/com.ojbkclub.petdfy_0.1.8-editable_*.deb root@手机IP:/var/mobile/
ssh root@手机IP "dpkg -i /var/mobile/com.ojbkclub.petdfy_0.1.8-editable_*.deb && killall -9 SpringBoard"
```

## 只换素材、不重编译

素材是**运行时读取**的，改完不需要编译，也不需要装包：

```bash
# 1) 把素材推到设备（保持 originals/ 与 live/ 的相对结构）
scp -r assets_src/originals/originals assets_src/live/* \
    root@手机IP:"/var/mobile/Library/Application Support/PetDFY.bundle/"

# 2) 让缓存失效：重启 SpringBoard，或在桌宠上长按 → 关掉再开「启用大肥鱼」
ssh root@手机IP "killall -9 SpringBoard"
```

如果只是想换一张脸/一件衣服的贴图，直接覆盖对应 PNG 再 respring 最快。

## 打包成可分发 deb（含素材）

```bash
make assets       # 把 assets_src/originals + live + PDLayout.json 塞进 layout/
make package
```

`make assets` 会让 deb 体积增加约 17 MB，但装上就有图，不用再走 App 内下载。

## 目录对照（安装后）

| 包内路径 | 设备路径 |
|---|---|
| `layout/Library/MobileSubstrate/DynamicLibraries/*.dylib` | `/Library/MobileSubstrate/DynamicLibraries/` |
| `layout/Library/Application Support/PetDFY.bundle/` | 同名 |
| `layout/Library/PreferenceBundles/PetDFYPrefs.bundle/` | 同名（设置页，含新增的「发色」分页） |
| `layout/Library/PreferenceLoader/Preferences/PetDFYPrefs.plist` | 同名（设置入口） |

## 编译报错速查

| 报错 | 原因 / 处理 |
|---|---|
| `'UIKit/UIKit.h' file not found` | 没设 `TARGET`/SDK；确认 `$THEOS/sdks` 有 iPhoneOS*.sdk |
| `undefined symbol: _MSHookMessageEx` | 少了 `PetDFY_LIBRARIES = substrate`，或设备没装 mobilesubstrate |
| `MTLTexture` 相关警告 | `-Wno-nullability-completeness` 已加；属正常 |
| arm64e 链接失败 | 老 Theos 的 ld 不支持 arm64e，把 `ARCHS` 收成 `arm64` 先跑通 |
