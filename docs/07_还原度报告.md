| 位置 | 状态 | 影响 |

| `WNRenderer encodeClip:` / `drawMesh:` | **部分**（未提交 `Appearance` uniform） | 剪裁矩形与 shader tint 未生效；发色走贴图注入，不受影响 |

发色在贴图层、服装与素材在数据层、布局在配置层——三处都和上面这些边缘实现无关。

# 本轮增补：指令级抬升（第三轮）

## 口径修正

上一版这里写过"指令加权 99.8%"，那是**只看方法体行数**得出的，会奖励"写得紧凑"、放过"边界缺失"。
本轮引入新口径并据此重做：

**证据保真度** = 二进制里实际用到的 selector / 导入符号 / CFString 常量，
在源码同名方法体里能不能找到等价表达（`tools/call_coverage.py`）。

| 口径 | 数值 | 说明 |
|---|---|---|
| 接口/结构 | **100%** | 54 类 / 1579 方法 / 588 ivar / 494 属性全部对齐 |
| 方法体存在 | **100%** | 无空壳（1464 个有实代码 + 115 个属性合成） |
| **证据保真度** | **66.3%** | 3666/5526 条证据命中（已排除 ARC/字面量/装箱噪音） |
| 待核方法 | **150 个 / 63404 条指令** | `docs/10_待还原清单.md`，按权重排序 |

## 本轮真正抬到"指令级等价"的方法

| 方法 | 指令 | 还原要点 |
|---|---|---|
| `WNRenderer meshesForParts:` | 361 | uvBox 是 `[u0,v0,u1,v1]`；索引是 **uint16**（`indexCount = len>>1`）；每格 6 个索引；`positionOffset` 按顶点字节累加；`multiply` 取 `blend=="multiply"` |
| `WNRenderer setStageSize:` | 59 | NaN/inf/非正/未变四个提前返回；quad 8 个 float；清 glowSurfaces |
| `WNRenderer liveFigureBounds` | 74 | 遍历 float2 求 AABB，`<8` 字节返回 `CGRectNull` |
| `WNRenderer drawMesh:positions:textureObject:look:encoder:` | 91 | **真实 ABI 是 80 字节 `Appearance` 指针**：`setFragmentBytes:length:0x50 atIndex:0`；索引绘制 offset 0 |
| `WNRenderer encodeClip:` | 591 | 共享 positions buffer、`space=(w,h,offx,offy)` atIndex:2、逐 mesh 组 `WNLook` |
| `WNLiveRig renderPointToStage:` | 127 | 缩放单位 10000、`rot` 以 0.1 度计、`AY` 四舍五入到 0.1、`out=(AX+dx·cos−dy·sin, AY+dx·sin+dy·cos)` |

顺带补上的一个真实缺陷：**`Appearance` uniform 之前根本没提交**（所以剪裁矩形与 shader tint 一直没生效）。
现在按二进制顺序提交，发色的 shader 通道（`c.rgb = mix(c.rgb, c.rgb*tint.rgb, tint.a)`）也随之可用。

## 结论

* **要能改内容（换装/素材/加衣服/布局/发色）的那部分，已经是完整可用状态**；
* **逐指令等价**当前是 66.3%（证据口径），剩余 150 个方法集中在：`WNPainter` 合成、`WNHitMask` 路径、
  `WNLiveRig` 变形器编译、`PDNative_MCPAX*`（AX 抓取）、`PDNative_AppManager`（安装/签名）、
  `PDChatService` / `PDAIPetRuntime` 编排、`PDSoundPlayer` 音符合成。
* 剩余工作已经**完全机械化**：每条都有指令数、缺口证据、目标地址，按 `docs/11` 的流程推进即可。
