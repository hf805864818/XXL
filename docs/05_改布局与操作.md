# 05 · 改布局与操作

原则：**凡是数值与开关，都不该在代码里**。这部分由 `PDLayout.json` 承担，
运行时读取，改完存盘 → 长按面板或发 `layout` 命令即生效（重编译完全不需要）。

## 文件在哪

按优先级：

1. `/var/mobile/Library/Application Support/PetDFY/PDLayout.json` ← 你的覆盖文件（建议只写要改的键）
2. `<PetDFY.bundle>/PDLayout.json` ← 随包默认
3. 内置默认值（`+[PDLayoutConfig defaultLayout]`）

文件是**深合并**的：你只写 `{"pet":{"scale":1.4}}`，其余键保持默认。

## 全部键

```json
{
  "pet":       { "scale": 1.0, "offsetX": 0, "offsetY": 0, "anchorBottom": 12, "anchorX": 0.7 },
  "stage":     { "padding": 0 },
  "interaction": { "padding": 6, "alphaThreshold": 0.12, "longPress": 0.45, "drag": 6 },
  "gesture":   { "single": "stroke", "double": "chat", "long": "menu",
                 "dragStart": "grab", "dragEnd": "drop" },
  "motion":    { "gravity": 1.0, "speed": 1.0, "jump": 1.0, "roam": "free" },
  "hud":       { "glow": true, "glowAlpha": 0.55 },
  "bubble":    { "fontSize": 15, "maxWidth": 260, "typing": 1.0 },
  "outfit":    { "default": "maid" },
  "scheme":    { "default": "deepseek" }
}
```

### pet —— 大小与位置

| 键 | 范围 | 说明 |
|---|---|---|
| `scale` | 0.2 – 6.0 | 在设置里「角色大小」(72–220) 之上再乘一次 |
| `offsetX` / `offsetY` | -400 – 400 | 像素微调，正数往右下 |
| `anchorBottom` | 0 – 600 | 距屏幕底部（覆盖设置里的 `BottomInset`，写了才覆盖） |
| `anchorX` | 0 – 1 | 水平锚点比例，默认 0.7（偏右）；0.5 居中、0 最左 |

### interaction —— 点哪儿算点到

| 键 | 说明 |
|---|---|
| `padding` | 命中轮廓外扩像素（0 = 严格按 alpha 蒙版） |
| `alphaThreshold` | 判定"实心"的 alpha 阈值；调大 → 只有很实的地方能点 |
| `longPress` | 长按判定秒数 |
| `drag` | 拖动判定位移阈值（像素） |

### gesture —— 手势映射（这一项最"可编辑"）

值可以是下列任意一个：

| 值 | 动作 |
|---|---|
| `none` | 什么都不做 |
| `chat` | 打开对话框 |
| `menu` | 弹出悬浮功能按钮 |
| `hair` | 打开长发色面板 |
| `outfitNext` / `outfitPrev` | 下一套 / 上一套服装 |
| `hide` | 隐藏角色（`Enabled = NO`） |
| `stroke` | 抚摸互动（原 `InputMode = stroke`） |
| `grab` | 拎起 |
| `voice` | 语音输入 |

例：把双击改成换装、长按改成发色面板：

```json
{ "gesture": { "double": "outfitNext", "long": "hair" } }
```

### motion —— 手感

| 键 | 影响 |
|---|---|
| `gravity` | 重力倍率（跳跃/坠落快慢） |
| `speed` | 自主移动速度倍率 |
| `jump` | 起跳力度倍率 |
| `roam` | `free` 活泼 / `calm` 安静 / `off` 只保留呼吸眨眼 |

### bubble —— 气泡

`fontSize`（8–40）、`maxWidth`（80–600）、`typing`（打字机速度 0–4，0 = 直接整段出现）。

## 生效方式

```bash
# 1) 写文件（设备上）
ssh root@手机IP 'cat > "/var/mobile/Library/Application Support/PetDFY/PDLayout.json"' <<'JSON'
{ "pet": { "scale": 1.3, "anchorX": 0.5 }, "gesture": { "double": "outfitNext" } }
JSON

# 2) 触发生效
#    a) 长按宠物 →「发色」面板 → 应用（顺手刷新）
#    b) 或用命令 layout（见 docs/02 的 performCommand 表）
#    c) 或 respring
ssh root@手机IP "killall -9 SpringBoard"
```

代码侧监听的是 `PDLayoutConfigDidChangeNotification`：
`PDOverlayController -onEditableConfigChanged:` → `reloadEditableAppearance`（重排 + 重建装配，不重挂窗口）。

## 想改「布局逻辑」而不只是数值

`PDOverlayController -layoutPet` 现在的算法：

```
baseW = 104 * preferences.size / 128 * layout.pet.scale
x     = (win.width - baseW) * anchorX + offsetX
y     = win.height - baseH - anchorBottom - safeArea.bottom + offsetY
（键盘弹出时再上移 keyboardAvoidanceExtra）
```

要换成"贴左边缘竖着走""桌面上排成一行"这类完全不同的布局，直接改这个方法即可——
它已经是纯数值计算 + 一处 `_pet.frame = f`，没有隐藏依赖。

## 排错

| 现象 | 原因 |
|---|---|
| 改了没反应 | 文件路径写错（注意 `Application Support` 里有空格，命令行要引号） |
| 部分键不生效 | JSON 语法错误 → 解析失败会**整份退回默认**；用 `python3 -m json.tool 文件` 校验 |
| 尺寸巨大/看不见 | `scale` 与设置里的「角色大小」是相乘关系，别两边都拉满 |
| 点不到角色 | `alphaThreshold` 调太高，或 `padding` 为负 |
