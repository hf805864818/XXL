# 04 · 添加一套新衣服

核心认知：**一套衣服 = `live/model.json` 里 `models` 的一个条目**（parts + z + grid + box + pivots + deformers）。
`box`/`grid` 是装配出来的几何，手写不现实；正确做法是**克隆最接近的一套，再只换贴图和 z**。

## 一条命令

```bash
python3 tools/add_outfit.py --id school --from sailor --title 校服
```

它会做四件事：

1. `assets_src/live/model.json`：`models["school"] = deepcopy(models["sailor"])`
2. 复制 sailor 的 9 张私有贴图到 `assets_src/originals/outfits/school/`，并把每个 part 的
   `src` 改指到新目录（→ 以后改 school 不会影响 sailor）
3. `assets_src/originals/model.json`：`outfits` 数组追加一份完整定义（源模型用，重编译需要）
4. `assets_src/originals/PDOutfitTitles.json`：写入 `{"school":"校服"}`（显示名数据化）
   ＋ 复制缩略图 `thumbs/school.png`

先看它要做什么：

```bash
python3 tools/add_outfit.py --id school --from sailor --title 校服 --dry-run
# 新服装 school（模板 sailor）：30 个部件，其中 9 个带私有贴图（outfits/jk-sailor）
```

## 然后改图

```
assets_src/originals/outfits/school/
├── arm_far.png  arm_far_end_front.png  arm_near.png
├── leg_back.png leg_front.png
├── skirt.png    skirt_sit.png  skirt_shadow.png
└── torso_up.png
```

规矩和普通素材一样：**画布尺寸必须和模板一致**（因为 `box` 没变）。

想让这套衣服有自己的头发/配饰，继续：

1. 往 `outfits/school/` 加 PNG（例如 `sailor_cap.png`）
2. 在 `live/model.json` 的 `models.school.parts` 里加一条：

```json
{ "id": "sailor_cap", "tex": "sailor_cap", "z": 13.4,
  "parent": "headFront", "grid": [4, 3],
  "box": [88.0, 46.0, 120.0, 60.0],
  "src": "outfits/school/sailor_cap.png" }
```

字段含义见 `docs/08`。`parent` 决定它跟哪个变形器（`headFront` 会跟着头部倾斜），
`z` 决定遮挡顺序（越大越靠前）。

## 第 3 步：让它在设置里出现（可选）

设置页的服装列表是 `Root.plist` 里的静态 specifier：

```
layout/Library/PreferenceBundles/PetDFYPrefs.bundle/Root.plist
  items[外装那一条]：
    validValues = ["maid","cape","crew","sailor"]
    validTitles = ["女仆装","冬装","店员装","jk水手服"]
```

各加一项即可（`validValues` 与 `validTitles` 顺序一一对应）：

```xml
<array>
  <string>maid</string><string>cape</string><string>crew</string><string>sailor</string>
  <string>school</string>
</array>
<array>
  <string>女仆装</string><string>冬装</string><string>店员装</string><string>jk水手服</string>
  <string>校服</string>
</array>
```

> 不补也行：长按 →「切换服装」是**动态目录**，会循环到 `school`。

## 为什么不用改代码

原实现有三处写死，全部拆掉了：

| 位置 | 原来 | 现在 |
|---|---|---|
| `PDOverlayController` `dress` 分支 | `@[@"maid",@"cape",@"crew",@"sailor"]` | `PDOutfitCatalog` 动态目录 |
| `PDPreferences reload` | `PDReadString(@"Outfit", @[@"maid"], @"maid")` | 任意非空 + 存在性校验 |
| `WNLiveRig textureForPart:` | `"<root>tex/<名字>.png"` 单模板 | 候选链（src → tex → outfits/<id> → originals → 用户包） |

## 真正的几何改动（进阶）

要改**形状**而不只是贴图，动 `live/model.json` 的 `parts`：

| 字段 | 含义 | 改动效果 |
|---|---|---|
| `box` | `[x, y, w, h]`，该 part 在舞台坐标系里的矩形 | 变位置/变大小（贴图会被拉伸到 box） |
| `grid` | `[cols, rows]`，网格细分 | 越细变形越平滑，代价是顶点数线性增长 |
| `z` | 绘制顺序 | 遮挡关系 |
| `parent` | 绑定的变形器名 | 决定是否跟随头/裙/尾/耳鳍的运动 |
| `alpha` | 该 part 的不透明度 | 半透明层（如阴影） |
| `blend` | `"multiply"` 等 | 阴影用乘算；走 `multiplyPipeline` |
| `uvBox` | 图集裁切区域 | 用图集（一张图多部件）时必须写 |

改完跑：

```bash
python3 tools/validate_assets.py --root assets_src        # 几何改了不会有缺失，但能查贴图
python3 tools/pack_assets.py --src assets_src --out build/assets
```

## 排错

| 现象 | 原因 |
|---|---|
| 新衣服切过去整体空白 | `parts` 空 / `tex` 名字打错 → 全部解析失败 |
| 只有某一块缺 | 那张 PNG 没放对目录或名字不等于 `tex` |
| 图错位、偏移 | 画的画布尺寸和模板不一致（`box` 是按模板尺寸定的） |
| 层级穿模 | `z` 与相邻部件冲突；z 相同的顺序不确定，尽量留 0.05 以上间距 |
| 变形很硬/很怪 | `grid` 太小；或 `parent` 填了不存在的变形器名 |
