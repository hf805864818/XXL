# 本地全功能编译与安装

> 2026-11-25：本机 arm64 + arm64e 全功能编译已通过，产物在 `dist/2026-11-25/`。

## 1. 工具链

两条路：

### A. CodexApp 自带 TheosRuntime（本机 iOS 上用）

```bash
R="/var/containers/Bundle/Application/<CodexApp-UUID>/CodexApp.app/TheosRuntime"
export THEOS="$R/theos"
export PATH="$R/usr/bin:$R/usr/lib/llvm-16/bin:$PATH"
```

### B. 标准 Theos

```bash
export THEOS=$HOME/theos
export PATH="$THEOS/bin:$PATH"
```

需要 `iPhoneOS16.5.sdk`（或更新），以及 `ldid`、`dpkg-deb`。

## 2. 编译

```bash
cd PetDFY-XXL
make clean all ARCHS="arm64 arm64e" TARGET=iphone:clang:16.5:16.0
```

成功判据：

```bash
ls .theos/obj/debug/arm64/PetDFY.dylib
ls .theos/obj/debug/arm64e/PetDFY.dylib
```

本次产物：

| 架构 | PetDFY | PDFYEnhance | PDFYSecurity |
|---|---:|---:|---:|
| arm64 | 2,454,752 B | 73,840 B | 66,864 B |
| arm64e | 2,511,696 B | 73,520 B | 66,768 B |

## 3. 素材与打包

```bash
make assets
# 然后二选一：
make package
# 或按 CI 的手工方式：把 .theos/_ 合并进 layout，再 dpkg-deb -b
```

素材不进 dylib，必须在 `layout/Library/Application Support/PetDFY.bundle/` 下存在：

```text
live/model.json
originals/
```

## 4. 安装（RootHide / rootless）

设备上的真实根不是 `/`，而是：

```text
/var/containers/Bundle/Application/.jbroot-<hash>/
```

把 deb 装进 jbroot，或先装到真实 `/Library` 再由 `postinst` 镜像。装完：

```bash
killall -9 SpringBoard
```

验证：

```bash
cat /var/mobile/Media/petdfy-probe.txt
# 期望：PDOverlayController = YES
```

## 5. 已知前置
