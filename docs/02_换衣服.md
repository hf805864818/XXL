# 02 · 换衣服

## 三种换法

### 1) 设置 App

设置 →「大肥鱼〇V〇」→「主题与服装 → 服装」→ 选一套。

> 这个列表原来是 `Root.plist` 里写死的 4 项（`maid/cape/crew/sailor`）。
> 加了新衣服想在这出现，往那条 cell 的 `validValues` / `validTitles` 各补一项即可（见 `docs/04`）。

### 2) 长按宠物 → 切换服装

长按 → 悬浮按钮 → `tshirt` 图标。点击后按**目录顺序**循环到下一套。

原实现（`PDOverlayController.m` 的 `dress` 分支）把 4 套写死成常量数组：

```objc
NSArray *outfits = @[@"maid", @"cape", @"crew", @"sailor"];   // ← 原样
NSUInteger idx = [outfits indexOfObject:self.preferences.outfit];
_PDAIWritePreferences(@{@"Outfit": outfits[(idx + 1) % outfits.count]});
```

现在改为向目录要数据，新加的衣服自动进入循环：

```objc
NSArray<NSDictionary *> *catalog = [PDOutfitCatalog catalogForRoot:... scheme:...];
NSString *next = [PDOutfitCatalog outfitAfter:self.preferences.outfit inCatalog:catalog];
```

### 3) 命令行 / 快捷指令 / 调试

`PDOverlayController` 的 `performCommand:` 新增了几个可编辑化命令：

| 命令 | 作用 |
|---|---|
| `outfit:crew` | 直接切到指定服装（存在才切，否则写日志） |
| `dress` | 循环下一套（同悬浮按钮） |
| `outfits` | 把当前可用服装目录打进系统日志（`NSLog`） |
| `hair` | 打开长发色面板 |
| `layout` | 重载 `PDLayout.json` |
| `assets` | 清空贴图缓存并重建（改完 PNG 立刻看效果） |

调用方式（任意一个即可）：

```bash
# 走 tweak 的 performCommand:
#   在 SpringBoard 里由 PDAIPetRuntime / 手势分发调用；
# 调试时也可以直接用 lldb attach 后执行：
(lldb) expr -l objc -- (void)[(id)[objc_getClass("PDOverlayController") performSelector:@selector(sharedInstance)] performCommand:@"outfit:crew"]
```

## 为什么服装"能自己长出来"

`PDOutfitCatalog` 的事实源有两个，都**不需要改代码**：

1. `live/model.json` 的 `models` 键 —— 每套服装是一段 parts 定义（含 z 顺序、网格、pivot）
2. `originals/outfits/<名字>/` 目录 —— 允许只放贴图的轻量服装

同时会做完整性检查：每个 part 的贴图能不能按候选链解析到（`complete` / `missing` 两个字段）。
不完整的服装也能切，但会缺图——用 `tools/validate_assets.py` 先体检。

## 主题（配色/品牌风）与服装是两个维度

* `Scheme`（deepseek / chatgpt / claude / gemini / harness / qwen / kimi / minimax）
  → 决定 `schemes/<名>/tex` + `feat` 里的配色与表情
* `Outfit`（maid / cape / crew / sailor / 你加的）
  → 决定身体与衣服的部件集合

原来的白名单把主题限成 `@[@"deepseek",@"doubao"]`、服装限成 `@[@"maid"]`，
等于"换装功能失效"。现在主题接受任意非空名，服装要求真实存在（否则回退到 `PDLayout.json` 的默认值并打日志）。

## 换装后发色是否保留

保留。`dress` 分支会把当前发色开关写回偏好，`resetLiveWithScheme:freeGround:` 重建装配后会重新注入染色贴图
（`WNRenderer+HairTint` 的 `pdApplyHairTintForParts:`）。所以换衣服不会掉色。

## 常见问题

| 现象 | 处理 |
|---|---|
| 点了没反应 | 检查 `Interactive` 是否为开；锁屏状态下悬浮按钮本来就不响应 |
| 切过去缺一块 | 该服装 part 缺贴图 → `python3 tools/validate_assets.py --root assets_src` 看 `缺：` 列表 |
| 切了以后还是老样子 | 用命令 `assets` 或 respring；贴图有 NSCache |
| 设置里看不到新衣服 | `Root.plist` 的 `Outfit` cell 是静态列表，见 `docs/04` 第 4 步 |
