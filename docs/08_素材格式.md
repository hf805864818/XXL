# 08 · 素材格式参考

## 文件树（PetDFY.bundle）

```
PetDFY.bundle/
├── Info.plist
├── Whale.metal               渲染着色器（源码字符串，运行期 newLibraryWithSource 编译）
├── asset-spec.json           素材包指针（下载/校验用）
├── asset-manifest.json       逐个文件的 bytes + sha256
├── .asset-state              安装状态
├── live/
│   └── model.json            装配后的模型（4 套服装 + 表情表）
└── originals/
    ├── model.json            源模型（units / pivots / parts / feat / schemes / outfits）
    ├── figure.json           人体骨架与尺寸参数
    ├── tex/*.png             身体/头发/脸/制服基础贴图
    ├── feat/*.png            表情部件（眼、嘴、高光、腮红）
    ├── outfits/<名字>/*.png  每套服装私有贴图
    ├── schemes/<主题>/       品牌配色主题（tex + feat 差异图）
    ├── props/toy-ball.png    玩具球
    └── thumbs/*.png          服装与主题的缩略图
```

## `live/model.json`

```jsonc
{
  "version": 1,
  "upstreamCommit": "dc1027…",
  "tables": {
    "faces":       { /* 表情名 → 参数 */ },
    "MOOD":        { /* 情绪名 → 数值 */ },
    "BROW": [..], "BROW_RATE": [..],
    "HEAD_TILT": [..], "HEAD_PITCH": [..],
    "HL_MOOD": [..], "MOUTH": [..], "MOUTH_DY": [..]
  },
  "models": {
    "maid": {
      "deformers": {                       // 变形器：名字 → 参数
        "headTilt": {...}, "hairSway": {...}, "bangsSway": {...},
        "skirt": {...}, "skirtSit": {...}, "tail": {...}, "tailBend": {...},
        "finNear": {...}, "finFar": {...}, "ahoge": {...},
        "armNear": {...}, "armFar": {...}, "legFront": {...}, "legBack": {...}
      },
      "parts": [ { "id": "...", "tex": "...", ... } ],   // 绘制单元，数组顺序无意义，z 决定层级
      "view": [-12, -8, 268, 272]          // 舞台可视矩形 [x, y, w, h]
    },
    "cape": { … }, "crew": { … }, "sailor": { … }
  }
}
```

### `parts[]` 字段

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `id` | string | ✓ | 部件标识；同服装内应唯一（重复会让 z 排序与命中蒙版错乱） |
| `tex` | string | ✓ | 贴图名（取 `<root>tex/<tex>.png`），可与 `id` 不同 |
| `src` | string | | 显式相对路径（相对主题根），服装私有贴图都是这种：`"outfits/jk-sailor/skirt.png"` |
| `z` | number | ✓ | 绘制顺序，越大越靠前（建议相邻留 0.05 以上） |
| `parent` | string | ✓ | 绑定的变形器名（`body`/`headFront`/`skirt`/`tail`/`finNear`…） |
| `grid` | [int,int] | ✓ | 网格细分 `[列, 行]`；越细变形越平滑，顶点数 = 乘积 |
| `box` | [x,y,w,h] | ✓ | 舞台坐标矩形（贴图被映射到这个矩形） |
| `uvBox` | [x,y,w,h] | | 图集裁切；用一张图放多个部件时必须写 |
| `alpha` | number | | 不透明度 0–1 |
| `blend` | string | | `"multiply"` 走乘算管线（阴影层用），缺省普通混合 |

### 贴图解析候选链（`PDTextureResolver`）

```
1) <主题根>/<src>                    例 originals/outfits/jk-sailor/skirt.png
2) <主题根>/tex/<tex>.png            originals/tex/skirt.png
3) <主题根>/outfits/<服装>/<tex>.png
4) <主题根>/outfits/<服装>/tex/<tex>.png
5) originals/…（第 2–4 条的 originals/ 版本，主题缺图时回退）
6) 用户素材包（UserPacks / AssetImports）
```

`<主题根>` = `originals/`（deepseek）或 `schemes/<主题>/`。

## `originals/model.json`（源模型）

```jsonc
{
  "units":   { "S": 0.19, "X0": 650, "FEET": 1363, "DS": 0.6, "featDS": 1 },
  "pivots":  { "body": [...], "waist": [...], "neck": [...], "armNear": [...],
               "armFar": [...], "legBack": [...], "legFront": [...], "tail": [...] },
  "parts":   [ ... ],                 // 基础部件（服装无关）
  "feat":    { "eyes": {...}, "sprites": {...}, "blush": [...], "skin": [...] },
  "schemes": [ { "id": "deepseek", "brand": "DeepSeek", "label": "原版",
                 "accent": "#4D6BFE", "ready": true, "eyeHighlights": true }, … ],
  "view":    [-12, -8, 268, 272],
  "outfits": [ { "id": "maid" },
               { "id": "cape", "parts": [...], "pivots": {...}, "deformers": {...} }, … ]
}
```

`units.S` 是舞台缩放比（0.19），`units.X0/FEET` 是原点与脚底参考值——改这两个会整体位移/缩放。

## `asset-spec.json` / `asset-manifest.json`

```jsonc
// asset-spec.json —— App 拿它去下载、校验
{ "schema": 1, "file": "PetDFY-assets.zip", "bytes": 16631170,
  "sha256": "ac63c715…",            // 素材 ZIP 本体
  "manifest_sha256": "449af073…",   // manifest.json 文件
  "asset_version": "ad294eba347cbc43" }

// asset-manifest.json
{ "asset_version": "ad294eba347cbc43",     // = content_sha256 前 16 位
  "content_sha256": "ad294eba…c8ce63",
  "files": { "originals/tex/hair_back.png": { "bytes": 45910, "sha256": "…" }, … } }
```

公式（已验证逐字节复现）：

```
content_sha256 = sha256( 对 files 按路径排序后拼接 "<path>:<sha256>\n" )
```

## `Whale.metal`（可直接改）

```metal
struct Appearance { float4 tint; float alpha; float pad0, pad1, pad2;
                    float4 clipX; float4 clipY; float4 clipRect; };

fragment float4 whaleFragment(...) {
    // 剪裁：用 clipX/clipY 把 stage 坐标投影到部件局部再判矩形
    if (look.clipX.w > 0.5) { … discard_fragment(); }
    float4 c = image.sample(linearSampler, in.uv);
    c.rgb = mix(c.rgb, c.rgb * look.tint.rgb, look.tint.a);   // ← 已有 tint 通道
    return c * look.alpha;
}
```

顶点着色器把 `positions[i]` 从舞台坐标归一化到裁剪空间：

```
p = (positions[i] + space.zw) / space.xy;
pos = float4(p.x*2-1, 1-p.y*2, 0, 1);
```

所以**改渲染风格**有两条路：

1. 改这个 `.metal`（改渐变、描边、发光、滤镜）——注意 `WNRenderer` 用
   `newLibraryWithSource:` 现场编译，改完 respring 即生效
2. 保持着色器不动，改贴图/部件（发色就是这么做的）

## 偏好键（`com.susudear.petdfyprefs`）

### 原有

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `Enabled` | bool | 1 | 总开关 |
| `Interactive` | bool | 1 | 允许触摸 |
| `Responsive` | bool | 1 | 响应式交互 |
| `Sound` | bool | 1 | 音效 |
| `InputMode` | str | `grab` | `grab` 拎起 / `stroke` 轻抚 |
| `DoubleTapAction` | str | `none` | `none/voice/chat` |
| `LongPressAction` | str | `menu` | `menu/voice/chat/none` |
| `Size` | num | 128 | 角色大小 72–220 |
| `PetScale` | num | 1 | 额外缩放 0.5–10 |
| `BottomInset` | num | 12 | 距底 |
| `KeyboardAvoidanceEnabled` | bool | 1 | 键盘避让 |
| `KeyboardAvoidanceExtra` | num | 0 | 额外上移 |
| `FPS` | num | 60 | 30/60/120 |
| `Scheme` | str | `deepseek` | 主题（任意主题目录名） |
| `Outfit` | str | `maid` | 服装（任意存在服装 id） |
| `Roam` | str | `free` | `free/calm/off` |
| `Theme` | str | — | `dark/light` |
| `PetOpacity` | num | 1.0 | 透明度（PDFYEnhance） |
| `PetScope` | str | `all` | `all/home`（PDFYEnhance） |
| `PetTapBubble` | bool | 1 | 单击气泡（PDFYEnhance） |
| `HoverButtons` | array | `[chat, voice]` | 悬浮按钮顺序，可含 `hair/dress/roam/sound/theme/hide` |
